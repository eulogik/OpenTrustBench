2026-09-18 — Coverage integrity v2

Trust-card/v2 ships: U (ungraded) where static coverage is insufficient, a coverage object in every card, CLI exit code 2 with all artifacts still written, and a --fail-on coverage gate. Registry recomputed under the stricter rule: 3 of 53 cards graded, 50 ungraded and excluded from rankings and averages. Withheld, never inflated. How coverage gating works.
